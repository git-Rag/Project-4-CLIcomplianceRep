# CLI compliance reporter — Project 2

This repository contains a portfolio-ready demo of **CLI compliance reporter**, Python project 4 using reportlab to generate a pdf report of the basic security functions in a computer.

## What is included
Core Idea: Write a command-line tool that runs mock system checks (e.g., password length, SSH root login, services status), stores results, and exports them as a PDF or text report. Concepts Covered: subprocess calls, loops, modular code, reportlab, CLI argument parsing.

## Run locally
1. Create a Python environment (Python 3.10+ recommended). (Optional)
2. Install dependencies:
       pip install reportlab
3. Run the app:
Run the project.
(>>python main.py --export pdf)
